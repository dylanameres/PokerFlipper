PokerFlipper

Type cards, run the sim, get equity.



      

        How to use the engine in code
        
import { simulateHand } from "./poker";

const result = simulateHand({
  hands: [["As", "Ah"], ["7d", "2c"]],
  board: [],          // optional
  iterations: 20000,  // optional, default 20000
});

console.log(result.equities); // e.g. [87.5, 12.5]
